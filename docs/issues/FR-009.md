# [FR-009] Codex SDK Runtime Manager

## Labels
`MUS`, `runtime`, `codex-sdk`

## User Story

As a builder, I want Takomi to run Codex sessions through a dedicated Codex SDK runtime manager so that execution remains consistent across Electron desktop and browser-safe runtime targets.

## Proposed Solution

### Overview

Implement a `CodexRuntimeManager` contract that abstracts desktop-local and remote/browser-safe runtime hosting while emitting one normalized stream of run events to the product.

### Implementation Flow

1. Define shared runtime contracts and event schemas.
2. Implement a desktop-local runtime host in Electron main.
3. Implement a remote/browser-safe runtime transport.
4. Normalize runtime output for transcript, orchestration, and audit consumers.

### Key Considerations

- Runtime failures must not corrupt session state.
- The renderer must never talk to native runtime facilities directly.
- Intervention actions must target the correct run owner across local and remote paths.

## Acceptance Criteria

- [ ] Takomi can start and monitor a Codex SDK-backed run through a shared contract.
- [ ] Runtime lifecycle events are surfaced in the UI and audit log.
- [ ] Desktop-local and remote/browser-safe execution stay shape-compatible.
